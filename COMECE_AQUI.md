# Comece aqui — OpenCode + DeepSeek

1. Leia `docs/GUIA_OPENCODE.md` e abra o OpenCode **nesta pasta**.
2. Selecione o DeepSeek com `/models`; conecte o provedor via `/connect`, se necessário.
3. Envie **somente o Prompt 0** de `docs/PROMPTS_OPENCODE.md`.
4. Siga F0 → F6 de `docs/PLANO_EXECUCAO.md`, uma fase por vez.
5. `AGENTS.md` impede expansão do escopo; `docs/PROGRESSO.md` documenta fatos; `docs/ACEITE.md` define entrega.

**Pacote é código-base existente + documentação de execução; não está homologado em Docker ou AWS.**
